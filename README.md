# README.md - Dello Móveis Planejados

Landing page responsiva de página única desenvolvida como projeto prático da Produção Textual Individual (PTI) de Fundamentos de Programação Web. O projeto simula a presença digital de uma empresa de pequeno porte especializada em móveis planejados sob medida.

## 🚀 Tecnologias Utilizadas

* **HTML5** (Estrutura semântica)
* **CSS3** (Estilização avançada com Flexbox, variáveis nativas e suporte a Dark Mode)
* **JavaScript** (Interatividade para menu hambúrguer, máscaras de formulário, animações de scroll e carrossel)

## 📌 Funcionalidades do Projeto

* **Design Responsivo:** Adaptado para computadores, tablets e smartphones utilizando Media Queries.
* **Seções Completas:** 
  * Cabeçalho fixo com navegação e links para redes sociais.
  * Seção Hero com carrossel dinâmico de fundo e cards de destaque sobrepostos.
  * Seção "Quem Somos" com apresentação institucional.
  * Carrossel de avaliações de clientes e galeria interativa de ambientes.
  * Seção de vantagens e benefícios.
  * Formulário de contato estilizado com validação visual.
* **Alternância de Tema:** Suporte a modo claro e escuro (Light/Dark Mode).

## 🛠️ Como Executar Localmente

1. Clone ou baixe este repositório para o seu computador.
2. Certifique-se de que a pasta de imagens está estruturada corretamente (pasta `imagens/` na raiz do projeto).
3. Abra o arquivo `index.html` em qualquer navegador web moderno.
